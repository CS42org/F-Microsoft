Right Click Menu Manager 2.0
Developed by CS42.org
Website: https://cs42.org
GitHub:  https://github.com/CS42org

HOW TO RUN
1. Extract this zip.
2. Run RightClickMenuManager.exe and click Yes when Windows asks for admin rights.
3. If Windows shows "Windows protected your PC", click More info, then Run anyway.

Works on Windows 10 and 11. No install needed.

WHAT IT DOES
- Turn items in the right click menu on or off, for files, folders, the desktop and drives.
- Filter by where you right click, kind (command or app extension), which menu
  (classic or Windows 11) and file type (images, videos, audio, documents, archives).
- Switch between the Windows 11 menu and the classic (Windows 10 style) menu.
- A backup is saved before every change. Restore any backup from Settings.

SHORTCUTS
Ctrl+F search, Space toggle, Ctrl+Z undo, Ctrl+S apply, F5 refresh, Esc close details.
